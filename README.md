# Todo List JS Sederhana

Todo List JS ini adalah aplikasi sederhana untuk mengelola task harian menggunakan **HTML, CSS, dan JavaScript**.  
Data tersimpan di **localStorage**, sehingga task tetap ada walaupun halaman direfresh.

## Fitur
- **Tambah Todo** – Masukkan task baru
- **Centang / Checklist** – Tandai task yang selesai
- **Hapus Todo** – Hapus task yang sudah tidak dibutuhkan
- **LocalStorage** – Data tersimpan otomatis di browser
- **Custom Scrollbar** – Tampilan modern untuk scroll
- **Responsive** – Bisa dijalankan di desktop dan mobile
